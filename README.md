# サッカーAI予想シミュレーション 公式ページ

このリポジトリは、App Store Connect に登録する以下のURLを兼ねる静的Webページです。

- マーケティングURL
- プライバシーポリシーURL
- サポートURL
- Google AdMob に関する説明

## 公開方法

GitHub Pages を有効にすると、`index.html` が公開ページになります。

1. GitHub のリポジトリ画面で `Settings` を開く
2. `Pages` を開く
3. `Build and deployment` の Source を `Deploy from a branch` にする
4. Branch を `master`、Folder を `/ (root)` にする
5. 表示された公開URLを App Store Connect の各URL欄に登録する
